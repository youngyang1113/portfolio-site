# Portfolio Site

这是一个基于 Next.js、Tailwind CSS、Framer Motion 和 Three.js 的个人品牌展示网站骨架。

## 特性

- 科技风首页设计
- 3D 交互场景
- 打字机效果自我介绍
- 时间轴与技能图谱
- 项目卡片与详情页面
- 博客列表与 MDX 协议占位
- 联系表单与社交链接

## 目录

- `app/`
  - `page.tsx`
  - `about/page.tsx`
  - `projects/page.tsx`
  - `projects/[slug]/page.tsx`
  - `blog/page.tsx`
  - `blog/[slug]/page.tsx`
- `components/`
- `lib/api.ts`
- `styles/globals.css`

## 安装

```bash
cd portfolio-site
npm install
npm run dev
```
